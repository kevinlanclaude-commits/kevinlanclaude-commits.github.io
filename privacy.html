Privacy Policy

Last updated: September 28, 2026

Kevin Personal Tools is a personal application used solely by its owner to access the owner's own Google account.

Data accessed

The application accesses Google user data (such as Gmail, Calendar, Drive, Docs, Sheets, Slides, and Tasks) only for the owner's account and only to perform tasks the owner requests.

Data use and sharing

No data is sold, shared with third parties, or used for advertising. Data is processed only on the owner's own devices. No data from any other user is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
